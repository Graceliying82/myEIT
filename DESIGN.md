# myEIT 3D Simulator Design Document

## 1. Overview
The **myEIT 3D Simulator** is a software tool designed to simulate Electrical Impedance Tomography (EIT) in a 3D environment. It demonstrates the interaction between a configurable electric field and a moving catheter (impedance anomaly), providing real-time 3D reconstruction/mapping of the catheter's position.

## 2. Architecture
The system follows a modular architecture:

- **Simulator Core (`simulator.py`)**: 
  - Responsible for the physics engine.
  - Manages the Mesh (FEM model).
  - Solves the Forward Problem (Voltage distribution from Conductivity).
  - Solves the Inverse Problem (Reconstructing Conductivity from Voltages).
  - Handles the "Catheter" logic (dynamic anomaly injection).
  
- **Visualization (`visualization.py`)**:
  - Uses `vispy` for hardware-accelerated 3D rendering.
  - Renders the EIT Mesh (pseudo-3D extrusion of the 2D physics model).
  - Displays the Electric Field/Conductivity distribution.
  - Visualizes the "True" catheter position vs. the "Reconstructed" position.

- **Controller (`main.py`)**:
  - The main application loop.
  - Handles user input (keyboard/mouse) to move the catheter.
  - Synchronizes the Simulator and Visualizer.

## 3. Technical Details

### 3.1 Physics Engine (pyEIT)
- **Mesh**: We currently utilize a high-density 2D mesh generated by `pyeit.mesh`. 3D visualization is achieved by extruding this mesh, ensuring computational stability while providing 3D spatial context.
- **Forward Model**: Uses the Finite Element Method (FEM) to simulate potential distributions.
- **Inverse Solver**: Algorithms like GREIT or JAC (Jacobian) are used for fast, real-time reconstruction.

### 3.2 Catheter Model
The catheter is modeled as a localized conductivity perturbation (anomaly). 
- **Position**: $(x, y)$ coordinates in the cross-sectional plane.
- **Properties**: High conductivity sphere/circle relative to the background.

## 4. User Interaction
- **Controls**: Arrow keys to move the catheter within the phantom.
- **Visual Feedback**: Real-time updates of the impedance map as the catheter moves.

## 5. Future Roadmap
- Full 3D tetrahedral mesh support (pending `pyeit` experimental features).
- Multi-plane impedance tracking.
- Integration with hardware data sources.
